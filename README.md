# Rock Paper Scissors

A browser-based rock paper scissors game built with vanilla JavaScript, HTML and CSS.
The first player to reach 5 points wins.

**[Play it online](https://nazaninsalehfar.github.io/rock-paper-scissors-js/)**

## Features
- Play against the computer with three move buttons
- Live score board for you and the computer
- The game ends when someone reaches 5 points, and the winner is announced
- Play again button to restart
- Keyboard accessible, with screen reader announcements for each round

## Tech
- HTML5
- CSS3 (Grid, custom properties)
- Vanilla JavaScript (no libraries or frameworks)

## What I practiced
- Separating game logic from DOM code
- Managing game state
- Handling events and updating the UI
- Accessibility basics (focus states, `aria-live`)

## Run locally
1. Clone the repo: `git clone https://github.com/NazaninSalehfar/rock-paper-scissors-js.git`
2. Open `index.html` in your browser
